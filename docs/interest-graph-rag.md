# 관심 논문 기반 Graph RAG

## 한 줄 요약

고정 데모 논문 그래프를 사용자 관심 논문·프로젝트 기반 Graph RAG로 확장했다.

## 문제

- 기존 Research Galaxy는 고정 PubMed 148편만 표시했다.
- 사용자가 저장한 관심 논문과 프로젝트가 그래프에 반영되지 않았다.
- 질문 결과는 관계 시각화까지만 제공하고 AI 답변으로 이어지지 않았다.

## 해결

- 기본 범위를 `전체 관심 논문`으로 변경했다.
- `미분류 / 프로젝트 / 데모` 범위 전환을 추가했다.
- 활성 관심 논문만 조회하고 모든 사용자·프로젝트 조건에 `is_del = false`를 적용했다.
- 제목+초록에서 주제, 핵심 개념, 내용 유사 관계를 요청 시 구성했다.
- 질문과 직접 연결된 최대 3편에서 그래프 이웃 3편까지 확장했다.
- 최대 6편의 서브그래프만 LangGraph 안전 검사를 거쳐 LLM에 전달했다.
- 답변 근거를 `직접 근거 / 그래프 이웃`으로 구분하고 논문 노드와 연결했다.

## 현재 흐름

```text
관심 논문 저장
  → 프로젝트 분류
  → 그래프 범위 선택
  → 제목+초록 관계 생성
  → 질문과 직접 관련된 논문 검색
  → 주제·개념·유사 연구 이웃 확장
  → 서브그래프 기반 AI 답변
  → PMID·논문 제목·연결 유형 확인
```

## 설계 판단

- 별도 그래프 DB를 추가하지 않았다. 기존 논문 데이터를 중복 저장하지 않는다.
- 그래프 구성에는 OpenAI API를 사용하지 않는다. 답변 요청 때만 사용한다.
- 그래프는 최근 관심 논문 최대 200편으로 제한해 응답 크기와 브라우저 부하를 제어한다.
- 현재 답변 근거는 제목+초록이다. 원문 전체를 읽었다고 오해하지 않도록 화면과 프롬프트에 명시했다.
- 원문 기반 상세 질문은 기존 채팅방의 `pgvector` RAG가 담당한다.

## 결과

- 로컬 사용자 관심 논문 51편이 기본 그래프로 표시됐다.
- 실질적인 Graph RAG가 직접 근거 3편과 그래프 이웃 3편을 사용해 답변했다.
- 서버 테스트 61개가 통과했다.
- 1440×900 화면에서 범위 선택, 답변, 출처 선택 레이아웃을 검증했다.

## 다음 개선

- 원문 청크와 그래프 관계를 함께 쓰는 하이브리드 Graph RAG
